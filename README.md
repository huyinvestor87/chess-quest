# ChessQuest ♟️

Nền tảng học cờ vua cho trẻ em theo lộ trình, giao diện tiếng Việt.

## Mục tiêu

ChessQuest giúp trẻ học cờ vua bài bản thông qua bài học ngắn, puzzle, thử thách, XP và theo dõi tiến độ.

## Tech stack đề xuất

- React + TypeScript + Vite
- chess.js
- Stockfish WASM (client-side)
- Supabase Free: Auth + Postgres + progress
- GitHub Pages hoặc Vercel/Cloudflare Pages

## Nguyên tắc sản phẩm

1. Học nền tảng trước, không học thuộc khai cuộc quá sớm.
2. Ưu tiên chiến thuật và tư duy CCT: Chiếu → Ăn quân → Đe dọa.
3. Nội dung ngắn, trực quan, phù hợp trẻ em.
4. Phụ huynh có thể theo dõi tiến độ.
5. Giao diện tiếng Việt là mặc định.
